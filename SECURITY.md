# Security

This is a personal project, but it answers a real phone number and holds real
callers' data, so reports are taken seriously.

If you find a vulnerability, please report it privately rather than in a public
issue: use GitHub's **Report a vulnerability** button under this repository's
Security tab. You will get a reply within a few days, and credit if you want it.

What is in scope: anything in this repository, and the deployed service at
talk.lewiswcampbell.com. Please do not test against the live phone number in a
way that would disturb real callers, and do not attempt to access other people's
call records.

The knowledge corpus and every credential live outside the repository. If you
believe one has leaked, that is the most important thing to report.

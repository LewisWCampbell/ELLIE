Every tool, and who can reach it

A tool is a function the model may call mid-conversation. Which set is offered depends on the channel, and that is a security boundary as much as a product one: the owner-only tools are never offered on a call, so no caller can talk their way into them.

ToolChannelWhat it does
save_user_factcall, webRemembers something about the caller. Also the path a verbal SMS opt-in takes, which records consent and sends the enrollment confirmation.
take_messagecall, webRecords something for the owner when Elle cannot answer it herself.
book_intro_callcall, web, SMSChecks free/busy across every configured calendar, writes a tentative hold, and notifies the owner. A slot lock in the database settles two callers racing for one time.
get_my_bookingsSMSLists what this number has booked.
reschedule_bookingSMSMoves a booking this number owns.
cancel_bookingSMSCancels a booking this number owns, freeing the slot.
show_workcall, webPuts a piece of work on the paired browser. A live page runs in a sandboxed iframe the caller can use; a screenshot renders as an image; a site that refuses embedding becomes a link card.
show_choicescall, webPuts a question with tappable options on the paired browser.
end_callcallEnds the call when the conversation is genuinely finished.
check_callsOWNER intakeReports who has called recently and what was learned, scoped per call.
check_outreachOWNER intakeShows which outreach messages were sent and which were answered.
send_outreachOWNER intakeSends a first message to a number the owner names.
voice_modeOWNER intakeSwitches the live voice architecture, with an expiry so a demonstration cannot silently become permanent.
